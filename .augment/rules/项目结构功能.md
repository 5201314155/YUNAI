1. 项目目标与 SLO
- 产品定位：YUNAI = AI 社交与创作平台。1 位用户 + N 位角色的剧场式群聊；朋友圈；通话；媒体生成（文生图/图生图/图生视频/文生视频/抠图/修复/动画）；关系网驱动行为与剧情触发。
- 关键体验：
  - 角色创建两图：背景图(bg_image) + 抠图(cutout_image)。单聊自动用背景图作背景；群聊发言自动切换抠图大图（300ms 淡入）；群聊有全局背景。
  - 剧情设定：世界/章节/场景可绑定触发；支持模糊触发与关联触发；触发后可切换全局背景/章节/风格/音效/音乐。
  - 媒体可参考：用户可上传参考图/参考视频参与生成；仅当模型与功能开关同时满足才在前端显示该能力。
  - AI 主动：关系/情绪/不活跃触发的“发消息/打电话/发动态”。
- SLO（默认）
  - 消息端到端：P95 < 1.2s，P99 < 2.0s
  - 媒体生成：第三方 P95 < 15s；ComfyUI/WebUI P95 < 40s（含降级链）
  - 语音通话：E2E < 250ms；虚拟人 < 500ms
  - 并发连接：WS ≥ 200k；SSE ≥ 100k
  - 可用性：平台 99.95%

2. 权限体系与功能曝光规则
- 用户等级
  - basic（普通用户）
  - vip（会员）
  - creator（创作者/作者工具权限）
  - admin（管理员/运营）
- 功能曝光公式（前端是否显示）
  - 可见 = 后台功能开关ON ∧ 模型具备该能力 ∧ 用户等级≥最低要求 ∧ 用户余额≥能力最低余额 ∧ 未达配额上限
- 资金与降级
  - 若余额不足：引导充值/卡密激活/自动切换低成本模型（可配置）
- 例：txt2video 在前端显示条件
  - feature_flags.txt2video_enabled = true
  - 用户 user_type ∈ {vip, creator, admin}
  - 所选模型.capabilities 含 txt2video
  - user.balance ≥ model.min_balance

3. 技术与架构总览
- 前端（Flutter）：go_router + Riverpod + freezed；dio + web_socket_channel；flutter_webrtc；Impeller；虚拟列表、图片解码隔离 Isolate；120/90/60Hz 自适配。
- 后端（Go 微服务）：chi + http2；gRPC + Protobuf；Kafka/NATS（事件总线）；PostgreSQL（分区/读写分离/Citus 可选）；Redis Cluster；Qdrant；S3/MinIO；Pion/Janus/LiveKit（RTC 信令/SFU）。
- 横切：
  - Provider Hub（模型/工作流统一）：参数 JSON Schema、健康、定价、权重、降级链、系统提示词。
  - Media Orchestrator：ComfyUI/WebUI/第三方流水线，预算/超时/降级。
  - Orchestrator（剧场）：上下文构建、关系注入、说话人调度、模型路由、扣费。
  - Memory & RAG：永久记忆、自动摘要、无感上下文切换、向量检索触发。
  - Feature Flags：灰度与个性化功能下发；前端动态组件渲染。
  - RBAC & 费控：统一权限判断与预算守卫。

4. 模型资源中心（Provider Hub）与能力管理
- 模型对象字段（核心）
  - id/internal_key、显示名称 display_name（前端可自定义）、provider、capabilities[]（chat/txt2img/img2img/img2video/txt2video/tts/stt/remove_bg/animation/...）
  - params_schema（JSON Schema；含类型、范围、默认值、中文别名）
  - model_system_prompt（全局模型提示词）
  - pricing（token/分钟/帧/步数/像素等）
  - visibility（public/vip_only/hidden）
  - permissions：min_user_type、min_balance、daily_limit/user_limit
  - health/weight/fallback_chain；connectivity_test_endpoint
- 能力覆盖
  - 接入协议：REST/WS/gRPC/Custom Bridge（脚本/容器）
  - 自托管：vLLM/TGI/FastChat；ComfyUI/WebUI 工作流（节点模板 → JSON Schema → 动态表单）
  - 用户自定义模型：我的接入（api_base、api_key、capabilities、params_schema、测试连通）
- 模型管理后台
  - 添加/删除/编辑、健康检查、试跑、定价、系统提示词、前端显示名、权限可见性、最低余额、限额、权重与降级链。
- 前端动态渲染
  - 仅在模型.capabilities ∧ flags 满足时渲染对应 UI（如“上传参考视频”“图生视频参数面板”）。

5. 关键业务模块说明与联动
- 角色（character）
  - 创建两图：bg_image + cutout_image；校验分辨率/透明边界。若启用生成功能：可文生图/图生图自动生成背景与抠图（自动抠图流水线）。
  - 绑定模型与参数；私密/公开；关系网编辑器；社交设置；触发规则（join_if/speak_if/escalate_if）。
- 聊天（单聊/群聊）
  - 单聊背景=角色背景图；群聊背景=群全局背景；发言者抠图 300ms 淡入；下一位预告；模型策略：统一/沿用角色/混合（按能力路由）。
- 故事与剧情
  - 世界/章节/场景；触发器（关键词/正则/情绪/关系强度/信任/嫉妒/时间窗/记忆命中/事件）；行为：切背景/切章节/切风格/切音乐音效/调度权重/安全策略。
  - 支持模糊触发（相似度、别称、共指）；冲突消解与优先级。
- 关系网
  - 类型库（系统/公共/私有）；关系边（强度、多维情感 metrics、称谓、语气、禁忌、触发、邀请策略、坚持/退让、提示词覆盖）；阶段与里程碑；私密继承。
- Moments（朋友圈）
  - 角色自动草稿 3–5 条；基于人设 + 最近聊天 + 长期记忆；文/动图/短视频/TalkingHead/3D；默认免审（可静默扫描）；复读保护（相似度去重）；“今天某某没找我”类自述；可见性：公开/好友/仅自己。
- 主动互动（Engagement）
  - 不活跃/强关系/嫉妒/剧情推进 → 发消息/来电（语音/视频/虚拟人）；频控/勿扰（冷却/时间窗配置）。
- 媒体工坊（Media Lab）
  - txt2img/img2img/remove_bg/inpaint/animate/img2video/txt2video/TalkingHead/3D/Avatar；支持参考图/参考视频；参数表单由 JSON Schema 自动生成；结果回填聊天/动态。
- 邀请拉人（AI propose → 用户确认）
  - 邀请卡：头像/理由/看点/预算提示；同意/拒绝/稍后；拒绝反应真人化并冷却；若缺失目标角色且用户允许 → 从公开池按标签/相容性推荐。
- 审核与可见性
  - 默认不审：聊天、朋友圈；需审：公开角色/世界/群资料/公共工作流/Provider/CMS；拒绝→自动转私密。
- 安全与合规
  - 登录/TOTP；加密(Argon2id/AES-GCM)；私有桶+签名 URL；CSP/SSRF 白名单/XSS；AI 合成角标+隐形水印；人像/语音合成首次授权。

7. 代码规范与协作流程
- 分支与提交
  - Trunk-Based + 短分支 + Feature Flags；分支命名：feat/…、fix/…；commitlint（feat/fix/docs/chore/refactor/test/build/ci）。
- 后端
  - 目录：transport/http|ws、service、repo、domain、jobs、pkg(auth/validate/obs)。
  - OpenAPI/AsyncAPI/Proto 单一事实源；sqlc；幂等（Idempotency-Key）；限流（Redis 令牌桶）；结构化日志；错误码 domain.reason。
- 前端
  - features/*/screens|components|states|repository
  - Riverpod Select 精准订阅；虚拟列表；图片预取与解码隔离；高刷策略封装为全局 service
- CI/CD
  - GitHub Actions + Buf + OpenAPI Diff + 单测覆盖闸门（后端≥70%、前端≥60%）→ 镜像签名（Cosign）→ ArgoCD → 金丝雀发布（Argo Rollouts）。

8. 测试策略与验收标准
- 测试金字塔
  - 单元（关系命中/调度/预算器/额度计算/折扣返利计算）、集成（DB/Redis/Qdrant/Provider 假服务 Testcontainers）、契约（OpenAPI/Proto/AsyncAPI）、E2E（登录→建群→演出→拉人→拒绝→动态→媒体→通话）、混沌（延迟/断网/队列积压）、性能（k6/Vegeta、RTC 延迟）。
- 关键验收
  - 角色两图渲染正确；群聊发言切图 ≤300ms；能力曝光规则正确（仅满足条件才显示）；剧情触发模糊命中有效（同义/共指/情绪）；媒体生成可参考图/视频；余额不足降级提示与引导；充值/卡密折扣/返利计算准确。

9. 监控、SRE 与上线运维
- 指标：QPS/延迟/P95/P99/错误率/WS连接数/RTC 房间/媒体成功率/降级率/成本/余额告警。
- 可观测：Prometheus + Grafana + OpenTelemetry + Loki + Tempo/Jaeger。
- 运维：多环境 dev/stg/prod；服务网格 mTLS；备份（数据库/对象存储跨区）；RPO ≤ 5min，RTO ≤ 15min。
- 灰度与回滚：错误率、延迟、成本暴涨阈值自动回滚，事后复盘（Postmortem）。

10. 定价、钱包与卡密（YUNAI 前缀）
- 金币：默认 1 元 = 10 金币（管理员可自定义）。
- 消费：按模型定价（token/分钟/帧/步/像素）+ 固定服务费；预算守卫。
- 卡密（前缀 YUNAI）
  - 折扣：按金额打折（100 金币原价 10 元，9 折=9 元）
  - 返利：返金币（充 100 金币，返 20 金币）
  - 特权：解锁功能（如 txt2video、高清 upscaler、TTS 高级音色）
- 示例计算（可写单测）
  - 输入：100 金币/单价 1 元=10 金币/折扣 0.9/返利 20%
    - 应付= 10 元×0.9 = 9 元
    - 到账金币= 100 + 20 = 120 金币

11. 风险与预案
- 成本失控：预算守卫、降级链、弹性限额、成本告警。
- 第三方不稳：健康检查、自动切换备用模型、本地工作流回退、熔断+退避。
- 关系与触发过多：服务端裁剪、客户端图谱折叠、>200 边降级渲染、命中缓存。
- 合规：公开项审核、自动重写/遮挡、AI 合成标识与隐形水印；人像/语音授权记录。
- 并发尖刺：WS 分片、背压、限流、慢消费者驱逐。

12. 里程碑与开发计划（含任务清单）

M2 角色系统与媒体生成（3–4 周）
