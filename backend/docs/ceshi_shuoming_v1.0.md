## 🔍 故障排除

### 常见问题

#### 1. 服务器启动失败
**症状**: 测试显示"服务器启动失败"
**解决方案**:
- 检查端口8092是否被占用
- 确认数据库连接配置正确
- 查看服务器日志获取详细错误信息

#### 2. 测试超时
**症状**: 测试显示"请求超时"
**解决方案**:
- 增加超时时间配置
- 检查网络连接
- 确认服务器响应正常

#### 3. API返回404
**症状**: 测试显示"状态码: 404"
**解决方案**:
- 确认API路由配置正确
- 检查服务器版本是否最新
- 验证请求路径拼写

### 调试技巧

1. **启用详细日志**: 修改日志级别为DEBUG
2. **单独测试**: 注释掉其他测试，单独运行失败的测试
3. **手动验证**: 使用curl或Postman手动测试API
4. **检查数据库**: 确认数据库中的数据状态
