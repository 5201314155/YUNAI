## 🔧 **模块1: 用户管理系统 (8个功能)**

### 1.1 用户注册功能
**功能描述**: 新用户通过邮箱注册账户
**测试步骤**:
1. 访问注册API `/api/v1/auth/register`
2. 提交用户信息: `username`, `email`, `password`
3. 验证邮箱格式和密码强度
4. 检查用户名唯一性
5. 创建用户记录并返回用户ID

**用户交互流程**:
```
用户输入 → 格式验证 → 唯一性检查 → 密码哈希 → 数据库存储 → 返回结果
```

**预期结果**:
- ✅ 成功创建用户记录
- ✅ 密码被正确哈希存储
- ✅ 返回用户ID和基本信息
- ❌ 重复用户名/邮箱被拒绝

### 1.2 用户登录功能
**功能描述**: 用户通过用户名/邮箱和密码登录
**测试步骤**:
1. 访问登录API `/api/v1/auth/login`
2. 提交登录凭据: `username/email`, `password`
3. 验证用户存在性
4. 验证密码正确性
5. 更新登录记录(IP、时间、次数)
6. 生成JWT Token

**用户交互流程**:
```
输入凭据 → 用户验证 → 密码验证 → 更新登录记录 → 生成Token → 返回认证信息
```

### 1.3 双因素认证(TOTP)
**功能描述**: 用户启用/使用TOTP双因素认证
**测试步骤**:
1. 生成TOTP密钥 `/api/v1/auth/totp/setup`
2. 用户扫描二维码或手动输入密钥
3. 验证TOTP码 `/api/v1/auth/totp/verify`
4. 启用TOTP功能
5. 登录时要求TOTP验证

**用户交互流程**:
```
请求启用 → 生成密钥 → 扫描二维码 → 输入验证码 → 启用成功 → 登录时验证
```

### 1.4 用户类型管理
**功能描述**: 管理用户类型(basic/vip/creator/admin)
**测试步骤**:
1. 查看用户类型 `/api/v1/users/{id}/type`
2. 管理员修改用户类型 `/api/v1/admin/users/{id}/type`
3. 验证权限变化
4. 测试不同类型的功能访问权限

### 1.5 账户状态管理
**功能描述**: 管理用户账户状态(激活/封禁)
**测试步骤**:
1. 查看账户状态 `/api/v1/users/{id}/status`
2. 管理员封禁用户 `/api/v1/admin/users/{id}/ban`
3. 设置封禁原因和到期时间
4. 验证被封禁用户无法登录
5. 解封用户账户

### 1.6 用户身份识别
**功能描述**: 多维度用户身份识别和行为分析
**测试步骤**:
1. 创建身份上下文 `/api/v1/users/{id}/identity`
2. 记录用户行为数据
3. 分析用户行为模式
4. 生成个性化推荐

### 1.7 登录记录追踪
**功能描述**: 记录用户登录历史和IP信息
**测试步骤**:
1. 用户登录时记录IP和时间
2. 查看登录历史 `/api/v1/users/{id}/login-history`
3. 统计登录次数和频率

### 1.8 用户资料管理
**功能描述**: 用户个人资料的增删改查
