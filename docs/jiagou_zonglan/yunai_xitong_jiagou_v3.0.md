## 摘要
YUNAI是一个功能完整的AI社交平台，集成了用户管理、角色系统、聊天编排、关系网络、智能邀请、媒体生成、故事演绎等核心功能。本文档详细描述了系统的整体架构设计和各模块间的交互关系。

## 系统概览

### 产品定位
YUNAI = AI社交与创作平台，提供1位用户 + N位AI角色的剧场式群聊体验，支持朋友圈、通话、媒体生成、关系网驱动的智能交互和故事演绎。

### 核心特色
- **智能社交**: 基于关系网络的AI主动邀请和互动
- **真实对话**: AI角色具备独特性格和情感表达
- **故事演绎**: 支持多元世界观和剧情适应
- **媒体创作**: 文生图、图生图、图生视频等创作能力
- **情感维护**: 完整的情感表达和关系维护机制

## 核心模块详解

### 1. 用户管理模块
- **功能**: 用户注册、登录、认证、权限管理
- **技术**: JWT认证、RBAC权限、Argon2id密码加密
- **特色**: 支持TOTP双因子认证、多级用户权限

### 2. 角色系统模块
- **功能**: 角色创建、编辑、性格设定、模型绑定
- **技术**: 动态性格系统、模型参数配置、角色状态管理
- **特色**: 两图创建（背景图+抠图）、性格一致性保证

### 3. 聊天编排模块
- **功能**: 单聊、群聊、消息路由、上下文管理
- **技术**: WebSocket实时通信、消息队列、上下文切换
- **特色**: 智能说话人调度、无感上下文切换、多模态消息

### 4. 关系网络模块
- **功能**: 关系定义、多维情感、关系强度计算
- **技术**: 图数据库设计、多维度关系建模、动态关系更新
- **特色**: 支持一对多关系、自定义关系类型、关系触发规则

### 5. 智能邀请模块 ⭐ **新增**
- **功能**: 关系驱动邀请、AI主动建议、完整响应流程
- **技术**: 自然语言处理、关系网络分析、情感计算
- **特色**: 只推荐有关系的角色、AI协作建议、情感补偿机制

### 6. 媒体生成模块
- **功能**: 文生图、图生图、图生视频、抠图、修复
- **技术**: Stable Diffusion、ComfyUI工作流、媒体流水线
- **特色**: 参考图生成、工作流模板、预算控制

### 7. 故事演绎模块 ⭐ **新增**
- **功能**: 多元世界观、剧情适应、角色一致性
- **技术**: 上下文感知、性格保持、氛围调节
- **特色**: 校园/悬疑/奇幻等多种设定、角色性格一致性

### 8. 计费系统模块
- **功能**: 金币系统、模型计费、卡密充值、折扣返利
- **技术**: 精确计费、预算守卫、事务一致性
- **特色**: 多种计费模式、卡密系统、自动降级

## 数据架构

### 数据库设计

#### 核心表结构
```sql
-- 用户表
users (id, username, email, password_hash, user_type, created_at)

-- 角色表
characters (id, user_id, name, personality, bg_image, cutout_image, model_id)

-- 关系类型表
relationship_types (id, name, description, user_id, is_system)

-- 角色关系表
character_relationships_enhanced (
    id, source_character_id, target_character_id, 
    relationship_type_id, custom_type_name,
    strength, trust, affection, respect, intimacy,
    tone, formality_level
)

-- 群聊表
group_chats (id, name, description, user_id, max_members, is_public)

-- 群聊成员表
group_chat_members (
    group_chat_id, user_id, character_id, 
    member_type, role, joined_at
)

-- 模型表
models (id, name, provider, capabilities, params_schema, pricing)

-- 钱包表
wallets (user_id, balance, total_spent, created_at)
```

#### 数据分区策略
- **时间分区**: 消息表按月分区
- **用户分区**: 大表按用户ID哈希分区
- **读写分离**: 主从复制，读写分离

### 缓存策略
- **用户会话**: Redis存储JWT token和用户状态
- **角色信息**: 热点角色数据缓存
- **关系网络**: 用户关系图谱缓存
- **模型配置**: 模型参数和能力缓存

### 向量数据库
- **用途**: 角色记忆、语义搜索、相似度匹配
- **技术**: Qdrant向量数据库
- **索引**: HNSW索引，支持高效相似度搜索

## 服务间通信

### 通信协议
- **HTTP/REST**: 外部API和前端通信
- **gRPC**: 内部服务间高性能通信
- **WebSocket**: 实时消息推送
- **消息队列**: 异步任务处理

### 服务发现
- **注册中心**: Consul/etcd
- **负载均衡**: 客户端负载均衡
- **健康检查**: 定期健康检查和自动故障转移

### 数据一致性
- **事务管理**: 分布式事务（Saga模式）
- **最终一致性**: 异步消息保证最终一致性
- **幂等性**: 所有API支持幂等操作

## 性能与扩展

### 性能指标
- **响应时间**: API P95 < 200ms
- **并发连接**: WebSocket ≥ 200k
- **消息吞吐**: ≥ 10k msg/s
- **AI生成**: 文本 < 2s，图像 < 15s

### 扩展策略
- **水平扩展**: 无状态服务，支持水平扩展
- **数据库扩展**: 读写分离、分库分表
- **缓存扩展**: Redis Cluster集群
- **CDN加速**: 静态资源和媒体文件CDN

### 监控告警
- **指标监控**: Prometheus + Grafana
- **链路追踪**: OpenTelemetry + Jaeger
- **日志聚合**: ELK Stack
- **告警通知**: 多渠道告警通知
