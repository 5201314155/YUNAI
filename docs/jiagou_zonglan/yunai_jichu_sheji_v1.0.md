## 产品定位与核心功能

### 产品定位
YUNAI = AI 社交与创作平台，提供沉浸式的 AI 角色互动体验。

### 核心功能模块
- **剧场式群聊**: 1 位用户 + N 位 AI 角色的智能对话
- **朋友圈**: AI 角色自动生成动态内容
- **实时通话**: 语音/视频/虚拟人通话
- **媒体工坊**: 文生图/图生图/图生视频等创作工具
- **关系网**: 角色间复杂关系与情感建模
- **剧情系统**: 基于触发器的动态剧情推进

## 技术架构总览

### 前端架构 (Flutter)
```
Flutter App
├── Presentation Layer (UI)
│   ├── Screens (页面)
│   ├── Components (组件)
│   └── Widgets (控件)
├── State Management (Riverpod)
│   ├── Providers (状态提供者)
│   ├── Notifiers (状态通知器)
│   └── States (状态模型)
├── Business Logic Layer
│   ├── Services (业务服务)
│   ├── Repositories (数据仓库)
│   └── Models (数据模型)
└── Data Layer
    ├── Remote Data Sources (远程数据源)
    ├── Local Data Sources (本地数据源)
    └── WebSocket/SSE (实时通信)
```

### 后端架构 (Go 微服务)
```
API Gateway (Kong/Envoy)
├── Auth Service (认证服务)
├── User Service (用户服务)
├── Character Service (角色服务)
├── Chat Service (聊天服务)
├── Media Service (媒体服务)
├── Relation Service (关系服务)
├── Orchestrator Service (编排服务)
├── Provider Hub Service (模型中心)
└── Notification Service (通知服务)
```

### 数据存储架构
```
数据层
├── PostgreSQL (主数据库)
│   ├── 用户数据
│   ├── 角色数据
│   ├── 聊天记录
│   └── 关系数据
├── Redis Cluster (缓存层)
│   ├── 会话缓存
│   ├── 频控数据
│   └── 实时状态
├── Qdrant (向量数据库)
│   ├── 角色记忆
│   ├── 语义检索
│   └── 相似度匹配
└── S3/MinIO (对象存储)
    ├── 媒体文件
    ├── 模型文件
    └── 备份数据
```

## 数据流设计

### 用户对话流程
```
用户输入 → API Gateway → Chat Service → Orchestrator Service
    ↓
关系网分析 ← Relation Service ← Memory & RAG Service
    ↓
模型调用 → Provider Hub → AI Model → 响应生成
    ↓
结果返回 → WebSocket → 前端渲染
```

### 媒体生成流程
```
生成请求 → Media Service → 参数验证 → 预算检查
    ↓
任务队列 → ComfyUI/WebUI → 生成处理 → 结果回调
    ↓
文件上传 → S3存储 → URL签名 → 前端展示
```

## 性能指标

### SLO 目标
- **消息端到端**: P95 < 1.2s, P99 < 2.0s
- **媒体生成**: 第三方 P95 < 15s, 本地 P95 < 40s
- **语音通话**: E2E < 250ms, 虚拟人 < 500ms
- **并发连接**: WS ≥ 200k, SSE ≥ 100k
- **可用性**: 平台 99.95%

### 扩展性设计
- 水平扩展: 微服务架构支持独立扩展
- 数据分片: PostgreSQL 分区表 + Citus 扩展
- 缓存策略: 多级缓存 + 预热机制
- 降级策略: 熔断器 + 备用方案

## 附录

### 技术选型理由
- **Flutter**: 跨平台、高性能、丰富生态
- **Go**: 高并发、简洁语法、快速编译
- **PostgreSQL**: ACID 特性、JSON 支持、扩展性
- **Redis**: 高性能缓存、丰富数据结构
- **Qdrant**: 向量检索、Rust 性能、易部署
