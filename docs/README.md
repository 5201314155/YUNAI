# YUNAI 项目文档中心

## 项目概述
YUNAI是一个功能完整的AI社交平台，提供智能角色对话、关系网络管理、媒体生成、故事演绎等核心功能。用户可以与AI角色进行真实自然的对话，体验基于关系网络的智能社交推荐，享受多元化的故事演绎体验。

## 项目状态

## 技术栈

### 前端
- **Flutter**: 跨平台移动应用开发
- **Riverpod**: 状态管理
- **go_router**: 路由管理
- **dio**: HTTP客户端

### 后端
- **Go**: 主要开发语言
- **PostgreSQL**: 主数据库
- **Redis**: 缓存和会话管理
- **Qdrant**: 向量数据库
- **MinIO**: 对象存储

### AI和媒体
- **DeepSeek**: 主要AI模型
- **ComfyUI**: 图像生成工作流
- **Stable Diffusion**: 图像生成
- **FFmpeg**: 媒体处理

## 核心特色

### 🤖 智能AI角色
- **真实性格**: 每个AI角色都有独特的性格特点
- **情感表达**: 丰富的情感表达和反应
- **一致性**: 在不同场景中保持角色一致性
- **成长性**: 角色能够学习和成长

### 🔗 关系网络驱动
- **多维关系**: 支持复杂的多维度关系建模
- **智能匹配**: 基于关系网络的智能推荐
- **动态更新**: 关系强度动态变化
- **个性化**: 支持用户自定义关系类型

### 💬 自然对话体验
- **上下文感知**: 理解对话上下文和历史
- **多模态**: 支持文本、图片、语音等多种形式
- **实时响应**: 低延迟的实时对话体验
- **群聊协作**: 多AI角色协作对话

### 🎭 故事演绎能力
- **多元世界观**: 校园、悬疑、奇幻等多种设定
- **剧情适应**: 角色能够适应不同的故事背景
- **氛围感知**: 根据剧情调整表达方式
- **互动推进**: 推动故事情节发展

### 🎨 媒体创作功能
- **AI绘画**: 文生图、图生图等创作功能
- **角色形象**: 自动生成角色背景图和抠图
- **参考生成**: 支持参考图片进行创作
- **多样化**: 支持多种艺术风格和主题
