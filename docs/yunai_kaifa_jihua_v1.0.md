## 📋 详细任务分解

### 🔐 认证授权系统任务

#### 1. JWT Token系统 (2天)
```go
// 需要实现的功能
- GenerateAccessToken(userID, userType) (string, error)
- GenerateRefreshToken(userID) (string, error)
- ValidateToken(token string) (*Claims, error)
- RefreshAccessToken(refreshToken) (string, error)
- RevokeToken(token string) error
```

#### 2. 密码管理系统 (2天)
```go
// 需要实现的功能
- HashPassword(password string) (string, error)
- VerifyPassword(hashedPassword, password string) bool
- ValidatePasswordStrength(password string) error
- GenerateRandomPassword() string
```

#### 3. 邮箱验证系统 (1天)
```go
// 需要实现的功能
- SendVerificationEmail(email, token string) error
- VerifyEmailToken(token string) (*User, error)
- ResendVerificationEmail(userID uuid.UUID) error
```

#### 4. 双因子认证 (1天)
```go
// 需要实现的功能
- GenerateTOTPSecret(userID uuid.UUID) (string, string, error)
- VerifyTOTPCode(userID uuid.UUID, code string) bool
- EnableTOTP(userID uuid.UUID, code string) error
- DisableTOTP(userID uuid.UUID, password string) error
```

#### 5. 密码重置 (1天)
```go
// 需要实现的功能
- SendPasswordResetEmail(email string) error
- ValidateResetToken(token string) (*User, error)
- ResetPassword(token, newPassword string) error
```
